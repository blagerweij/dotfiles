# Hammerspoon 2 config

Port of `~/.hammerspoon` to [Hammerspoon 2](https://cmsj.github.io/Hammerspoon2/main/js/index.html).

## Window management
- `ctrl + ⌥ + ⌘ + Left`  - move window to the left half of the screen
- `ctrl + ⌥ + ⌘ + Right` - move window to the right half of the screen
- `ctrl + ⌥ + Enter` - maximize window
- `ctrl + ⌥ + ⌘ + M` - toggle fullscreen mode

## Screen management
- `ctrl + ⌥ + ⌘ + Up`  - move window to the next monitor
- `ctrl + ⌥ + ⌘ + Down`  - move window to the previous monitor

## Other
- `⌥ + space` - switch between terminal and focussed app
- `ctrl + ⌥ + ⌘ + space` - app / IntelliJ project launcher
- `ctrl (2x)` - show location of mouse (rings show ping to 8.8.8.8)
- `ctrl + ⌥ + space` / `F20` - toggle microphone mute (also Zoom / Teams)
- `ctrl + ⌥ + ⌘ + P` - Spotify play/pause
- `ctrl + ⌥ + ⌘ + R` - new reminder
- `ctrl + ⌥ + ⌘ + Z` - join a Zoom/Teams meeting from your Outlook calendar (needs `zoom.json`)
- `⇧ + ⌘ + S` - start Zoom screen share
- `ctrl + A` - draw on screen with the left mouse button (`ctrl + A` / `Esc` to stop). While drawing: `F` free draw, `L` line, `R` rectangle, `O` ellipse, `1`-`6` red/green/blue/yellow/white/black
- `ctrl + S` - spotlight: dim the screen except around the mouse (`ctrl + S` again to stop)
- `ctrl + L` - highlight: circle around the mouse cursor (`ctrl + L` again to stop)

`time-machine.js` (disabled in `init.js`) excludes caches and build folders from Time Machine.
